# 记忆翻牌 · 大脑训练营

网页版记忆翻牌游戏，用来锻炼记忆力。纯前端实现（HTML/CSS/JS），不需要构建工具，双击 `index.html` 就能玩。

## 玩法

| 模式 | 规则 |
| --- | --- |
| 经典 | 翻开两张相同的卡片配对，步数越少星越多 |
| 闯关 | 关卡逐步变大，预览变短；每 5 关是三连 Boss 关，第 6 关起会洗牌；记忆失误扣生命 |
| 限时 | 倒计时内尽量多配对，配对加时、连击加更多，清空一盘自动发下一盘 |
| 三连 | 一次翻三张，三张相同才算成功 |
| 洗牌 | 每走几步，两张背面朝上的卡会交换位置，要盯住它们 |

- **开局预览**：所有卡片清晰亮出，顶部倒计时；记住了可以点「我记住了」（或按 Enter）提前开始，剩余秒数折算成加分。预览时长可选 关闭 / 短 / 标准 / 长。
- **记忆失误**：翻开的第一张卡，它的同伴之前已经翻开过，你却没翻对，就算一次记忆失误（扣分 / 扣时间 / 扣生命）。
- **道具**：提示（亮出一组；已翻开一张时直接亮出它的同伴）、透视（短暂亮出全部）。
- **六档难度**：入门 6 组 → 大师 18 组，棋盘会自动排成能放下的最大卡片尺寸。

## 卡面

形状（自绘 SVG，组数多时同形不同色）、水果、动物、美食、游戏、数字、形近字（日目田由甲申…）、大杂烩。

## 其他

- 浅色 / 深色模式，音效开关
- 按「模式 + 难度 + 卡面」记录最高分；闯关记录已解锁关卡和每关星级（localStorage）
- 快捷键：P / Esc 暂停，H 提示，V 透视，Enter 结束预览
- 切到别的窗口会自动暂停，暂停时卡片隐藏

## 本地运行

直接打开 `index.html`，或用任意静态服务器：

```bash
python -m http.server 8420
```

然后访问 `http://localhost:8420`。

## 文件结构

- `index.html` — 页面结构
- `style.css` — 设计变量、卡片样式与动画
- `script.js` — 游戏逻辑（模式、计分、洗牌、道具、存档）
