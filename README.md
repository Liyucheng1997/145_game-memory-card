# 记忆翻牌 · 大脑训练营

一个可调节难度的网页版记忆翻牌游戏，用来锻炼记忆力。纯前端实现（HTML/CSS/JS），无需构建工具，双击 `index.html` 即可玩。

## 特性

- **6 档难度**：简单 / 中等 / 困难 / 专家 / 大师，外加自定义对数滑块（4~18 对），自动计算网格排布
- **7 种卡片主题**：数字、颜色、花卉、鸟类、水果、动物、混合惊喜（随机混搭）
- **记忆预览**：开局可选择先亮出所有卡片几秒钟再开始挑战，也可关闭以提升难度
- **实时数据**：计时、步数、连击、得分，通关有星级评价与限时得分加成
- **本地最佳成绩**：按“难度 + 主题”分别记录最高分（localStorage）
- **音效与撒花动画**：WebAudio 音效、静音开关、通关撒花特效
- **暂停 / 继续 / 重开 / 更换设置**

## 本地运行

直接打开 `index.html`，或用任意静态服务器：

```bash
python -m http.server 8420
```

然后访问 `http://localhost:8420`。

## 文件结构

- `index.html` — 页面结构
- `style.css` — 视觉样式与翻牌动画
- `script.js` — 游戏逻辑
